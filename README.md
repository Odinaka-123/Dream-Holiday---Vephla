**🌍 Dream Vacation Gallery**

A modern multi-page gallery website showcasing dream vacation destinations using a glassmorphism UI design.
This project focuses on clean layout, visual storytelling, and consistent styling across multiple pages.

**📌 Project Overview**

The Dream Vacation Gallery is a static website built with HTML and CSS.
It presents a visually immersive gallery of travel destinations, designed to look modern and elegant while remaining simple and accessible.

The project demonstrates:

Multi-page website structure

Consistent UI design

Responsive layout principles

Proper use of semantic HTML and CSS styling

**🧭 Pages Included**

Home – Introduces the gallery with a hero image

Destinations – Highlights different types of dream locations

Gallery – A full visual gallery of vacation images

Each page includes a navigation menu for easy access.

🛠️ Technologies Used

HTML5

CSS3

CSS Flexbox & Grid

Glassmorphism UI (blur, transparency, layering)

**🎨 UI & Design Features**

Glassmorphism effect using backdrop-filter

Responsive layout with viewport meta tag

Hover animations for images and cards

Clean typography and spacing

Consistent styling across all pages

🖼️ Images & Accessibility

Includes 5+ images

All images contain descriptive alt attributes

Images are organized in a dedicated images folder
